# Auto-Email Birthday Reminder

This workflow sends **automatic birthday wishes** via Gmail using data from **Google Sheets** and messages generated by **Google Gemini AI**.

Runs every day at **8:30 AM** → Sends an email only if someone's birthday matches today.

---

## What It Does
- Reads `Name`, `Birthday`, `Email` from Google Sheets  
- Detects birthdays (MM-DD match)
- Calculates recipient age
- Uses Gemini to generate a personalized message
- Sends greeting email via Gmail — fully automated

---

## Google Sheet Format
| Name | Birthday (YYYY-MM-DD) | Email |
|------|-----------------------|--------|

---

## Workflow Nodes
1️⃣ Schedule Trigger  
2️⃣ Google Sheets → Get Data  
3️⃣ Function → Filter birthdays + calculate age  
4️⃣ Gemini → Generate message  
5️⃣ Gmail → Send email

---

## Required Credentials
- Google Sheets OAuth2  
- Google Gemini / PaLM  
- Gmail OAuth2
